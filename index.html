const FIREBASE_URL = "https://sports-day-a03f9-default-rtdb.firebaseio.com/";

🔒 Firebase 권한 오류

Firebase 데이터베이스 규칙이 쓰기를 막고 있어요.
아래 방법으로 규칙을 수정해 주세요.

📋 Firebase Console → Realtime Database → 규칙(Rules) 탭
아래 내용으로 교체 후 게시 클릭:
{ "rules": { ".read": true, ".write": true } }
※ 행사 당일에만 사용하고 이후 규칙을 잠가주세요
